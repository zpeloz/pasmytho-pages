Connexion TikTok

Pas Mytho Stats · réservé au créateur de @pasmytho

Cette page t'envoie sur TikTok pour autoriser le relevé quotidien de tes statistiques. Rien n'est enregistré ici : la clé ne sert qu'à construire le lien vers TikTok.

Ensuite
  1. TikTok te renvoie sur la page « Retour » avec un code.
  2. Copie ce code et colle-le dans l'action « Connexion TikTok » du dépôt privé pasmytho-releve.
  3. Fais-le dans les minutes qui suivent : le code expire vite.
